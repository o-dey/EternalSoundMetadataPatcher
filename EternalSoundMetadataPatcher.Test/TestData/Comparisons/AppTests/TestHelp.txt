Usage: EternalSoundMetadataPatcher [-h] [-b] [-v] [-d] [-no-snd-fix] <path to idstudio mod directory> <path to Wwise project directory>

Options:
	-h	Display this help.
	-b	Backup mode/limit (defaults to 10). -1 for "unlimited" backup files. 0 to disable backups.
		>= 1 to define the maximum number of backups (when the limit is reached, backup names will rotate).
	-v	Show verbose output.
	-d	Show debug level output.
	-no-snd-fix	Disable sound container fix.
